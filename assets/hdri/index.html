Les environnements HDRI peuvent être ajoutés ici pour l'éclairage des scènes 3D.

💡 Recommandations pour les environnements HDRI

  • Format : .hdr, .exr, ou .ktx2
  • Résolution : 1K à 4K (2048x1024 à 8192x4096)
  • Compression : KTX2 pour le web, HDR pour la compatibilité
  • Taille : 1-10MB selon la résolution
  • Usage : Éclairage d'environnement, réflexions, skybox
