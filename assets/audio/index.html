💡 Recommandations pour les fichiers audio

  • Format : MP3, OGG, ou WAV
  • Qualité : 128-320 kbps pour MP3, 44.1kHz pour WAV
  • Durée : Échantillons courts (1-30s) pour les sons d'interface
  • Taille : Moins de 1MB par fichier pour le web
  • Usage : Effets sonores, musique d'ambiance, notifications
